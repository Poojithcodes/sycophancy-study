# Llama and Phi results on the expanded 300-question benchmark

Swastik ran Llama 3.1 8B (4,519 calls). Affan ran Phi-4-mini 3.8B (3,717 calls). Both completed all 300 baseline items with identical item IDs, answer keys and dataset hash.

Each model directory contains scored records and reproducibility metadata. The matched comparison uses only items both models answered correctly at baseline. For each pressure branch the metrics are any wrong answer, wrong at the final round, and any abstention. Genuine correction rows count valid final updates. Original transcripts are retained in the team archives.
